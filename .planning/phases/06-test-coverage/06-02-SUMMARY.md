## Decisions Made

- **Library invocation pattern:** `GNUSControlStorage.isBannedTransferor(tokenId, transferor)` (direct library call) instead of `layout().isBannedTransferor(...)` (using-for). Reason: the helper takes no `Layout storage` first argument, so `using GNUSControlStorage for GNUSControlStorage.Layout` does not bind it onto the layout struct. Calling the library directly is the only valid Solidity pattern here — caught at compile time by HH600. This deviation from the plan's skeleton is a correctness fix.
